`json-pack` implements the fastest JSON serialization and deserialization algorithms
in NPM ecosystem. This module implements [CBOR][cbor], [MessagePack][msgpack],
[JSON][json], and [UBJSON][ubjson] codecs. The module does not use any external
dependencies and it works, both, in Node.js and in browsers.

[cbor]: https://cbor.io/
[msgpack]: https://msgpack.org/
[json]: https://www.json.org/json-en.html
[ubjson]: http://ubjson.org/
