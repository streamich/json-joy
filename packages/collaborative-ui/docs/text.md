## Collaborative UI library

A library of React components for building rich real-time collaborative editing
experiences on top of [json-joy](https://jsonjoy.com) JSON CRDT.


## Installation

```
npm install json-joy @jsonjoy.com/collaborative-ui
```


## Usage

Import components from their subpaths:

```tsx
import {MyComponent} from '@jsonjoy.com/collaborative-ui/lib/MyComponent';

<MyComponent {...props} />
```
