`BlobFace` is a playful inline mascot component.

It renders a rounded blob character with eyes that track the cursor, blink from
time to time, and slip into small idle gestures like tilts and winks. When the
blob is hovered, it swells into a soft wave and its eyes flatten into a
satisfied expression.

```tsx
import {BlobFace} from '@jsonjoy.com/ui/lib/1-inline/BlobFace';

<BlobFace size={32} />
```
